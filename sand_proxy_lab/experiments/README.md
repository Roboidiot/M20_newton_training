# 沙地代理离线结构实验

## 纯滑移响应：2026-10-29

从项目根目录运行：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  .venv/bin/python -m sand_proxy_lab.experiments.sliding_only --terrain m20_sand_v1
```

默认结果写入该地形的 `fit/sliding_only/<时间戳>/`；可用 `--output-dir` 指定新目录。
输入为已有的整机拟合轨迹、独立前进轨迹、随机动作第一回合及 179 组足端探针数据。
输出包含独立的 12 参数纯滑移候选、原始采样回放、参数与输入哈希、逐工况指标和对比图。

实验比较当前混合模型、直接删除基底、只用整机训练段重拟合，以及直接联合整机/探针训练数据拟合。
两个拟合实验均不标定或使用弹塑性基底参数。训练/验证划分不变；三个固定初值只按训练损失选择。
联合拟合另外将承载系数上界从 150 N 放宽到 10000 N，并将两来源的归一化损失等权，属于补充实验。
纯滑移候选使用独立实验格式，当前训练运行时不会加载，默认部署参数不变。

本次结果保存在
[`20261029_comparison/report.md`](../../output/sand_proxy/terrains/m20_sand_v1/fit/sliding_only/20261029_comparison/report.md)。
以下均为原始物理步上的 Fx/Fy/Fz RMSE，单位 N：

| 数据 | 当前混合模型 | 纯滑移，整机训练段重拟合 |
|---|---|---|
| 同轨迹时间留出 | 78.60 / 11.82 / 9.63 | 78.24 / 11.82 / 9.40 |
| 独立前进轨迹 | 11.92 / 1.78 / 3.42 | 11.92 / 1.78 / 3.42 |
| 独立随机动作回合 | 72.67 / 24.15 / 36.40 | 72.67 / 24.15 / 36.46 |

独立前进/随机动作轨迹中，预热后正深度样本的当前滑移分支权重全部大于 0.99，
所以删除基底后运动误差几乎不变。三次初值收敛到相同训练损失。

静止时纯滑移式只剩 `B(d)`。在 0–28 cm 深度范围，整机训练段重拟合模型的四足最大静态承载为
**48.38 N**，约占整机 **338.36 N** 重量的 **14.3%**，没有四足均载静止平衡。
探针压入验证的主轴平均 RMSE 从当前模型的 **26.24 N** 增至 **1408.20 N**。
联合拟合提高承载至 **205.72 N**，仍不足；独立前进的 Fz RMSE 增至 **32.07 N**，
随机动作的 Fy 改善至 **16.89 N**，但 Fz 恶化至 **43.11 N**。

因此，本次实验不支持原样用纯滑移式替换当前训练模型。
这些是离线受力回放与解析静止承载检查，没有进行新 MPM 采集、整机闭环支撑仿真或 PPO 训练。
若取消弹塑性状态，仍需设计与辨识足够的静态承载项，并另做独立验证与闭环检查。

## 用随机动作影子数据重拟合纯滑移响应：2026-10-29

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  .venv/bin/python -m sand_proxy_lab.experiments.random_sliding --terrain m20_sand_v1
```

本次结果位于
[`20261029_random_refit/report.md`](../../output/sand_proxy/terrains/m20_sand_v1/fit/sliding_random/20261029_random_refit/report.md)。
输入为 `shadow/random_30s_001/traces.npz` 实际保存的 7 秒数据，不读取探针数据。
前进拟合版对照来自前一实验的 `20261029_comparison/sliding_shadow_fit.json`。

- `random_blocked_fit.json`：回合 0 的 0.5–4 秒拟合，5600 个正深度足端样本；
  回合 0 的 4.2–6 秒与回合 1 预热后的 0.5 秒保留验证。
- `random_all_fit.json`：两个回合全部非预热样本拟合，共 9600 个足端样本；
  其随机数据误差为拟合内误差。
- 两版均使用原纯滑移 12 参数公式、原边界和三个固定初值；只按训练损失选择初值。
- 两条已有前进轨迹均未参加此次拟合。原始数据、当前部署参数及既有结果不变。

三轴 RMSE（Fx/Fy/Fz，N）如下：

| 数据 | 原前进拟合版 | 随机时间划分版 |
|---|---|---|
| 回合 0 时间留出 | 92.40 / 19.76 / 15.92 | 69.09 / 21.51 / 15.93 |
| 回合 1 短验证 | 35.95 / 30.12 / 58.37 | 30.88 / 14.85 / 33.22 |
| 独立低速前进 | 11.92 / 1.78 / 3.42 | 24.83 / 2.17 / 21.17 |

全随机数据版的拟合内 RMSE 为 **49.27 / 16.39 / 25.56 N**，相对原前进拟合版在同一批样本上的
**70.34 / 24.70 / 38.76 N**，分别降低约 **30.0% / 33.7% / 34.1%**。
但其水平 NRMSE 仍为 **35.4% / 49.3%**，未通过原 25% 判据；前进工况精度有所退化。
本次结果显示随机数据有助于改善随机动作受力拟合，但未实现对各已有工况均吻合。
